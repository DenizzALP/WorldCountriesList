# 🌍 World Countries Search App

This is a simple and interactive frontend project that displays a list of all 193 countries. Users can filter and search countries based on three different criteria and see the matching results live on the screen.

## Features

- Display all countries in styled boxes.
- **Search modes:**
  - `STARTING WORD`: filters countries that start with the search input.
  - `SEARCH WITH ANY WORD`: filters countries that contain the search input anywhere.
  - `A-Z`: shows the full list of countries in alphabetical order.
- Real-time search experience.
- Background image with overlay.
- Clean and responsive CSS design.

## Technologies Used

- HTML
- CSS
- JavaScript (DOM Manipulation)
- Font Awesome (search icon)

## Usage

1. Clone the project to your local machine:

    ```bash
    git clone https://github.com/DenizzALP/WorldCountriesList.git
    ```

2. Open the HTML file in your browser to use the app.

3. No server is required to run the app; simply open the HTML file in a browser.
